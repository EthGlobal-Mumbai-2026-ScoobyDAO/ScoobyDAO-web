# Models

Drop compressed `.glb` files here and flip the flag in `manifest.json`:

- `sniff.glb` → `"sniff": true` (clips: `idle`, `sniff`, `alert`, `triumph`; < 3 MB; see THEME.md §3–4)
- `mask.glb` → `"mask": true` (< 500 KB)

Until then the hero renders a stylised placeholder hound and the resolve moment uses a procedural coin mask.
